# SpotifyPlaylistMerger
## A Python application that uses the Spotify Web API to merge multiple Spotify playlists into one massive playlist.
<br>

## Why I Made This
I had dozens of Spotify playlists across different genres, each containing hundreds of songs. Switching between playlists constantly became annoying, so I wanted a way to combine all my music into one giant playlist containing every song I listen to.

This project connects to your Spotify account through the Spotify API, fetches your playlists, and allows you to merge selected playlists into a single mega playlist.

<br>

## Features
- Merge multiple playlists
- Remove duplicate songs
- Fetch playlist data directly from the Spotify API
- Simple command-line interface
- Secure authentication using environment variables

<br>

## Tech Stack
- Python
- Spotipy
- Spotify Web API
- python-dotenv
